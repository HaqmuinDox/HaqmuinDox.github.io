jtx Board is a solid Android app for journals, notes and to-dos, and it syncs over CalDAV, but it
only runs on a phone. jtx Desktop is the companion I wanted on a laptop.

It is an Electron app that keeps everything in a local SQLite database, so it opens instantly and
works with no connection at all. Once it is online it syncs both ways with a self-hosted Nextcloud
over CalDAV, reconciling whatever changed on either side. The interface is React and TypeScript,
kept deliberately plain: a list, an editor, and not much else.
