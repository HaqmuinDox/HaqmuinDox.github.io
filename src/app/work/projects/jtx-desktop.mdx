## Overview

jtx Desktop is a local-first desktop companion to jtx Board. It manages journals, notes and
to-dos in a local SQLite database and syncs both ways with Nextcloud over CalDAV, so the app works
fully offline and reconciles once a connection is available.

## What it does

- Stores everything locally in SQLite, so the app is fast and usable with no network.
- Two-way CalDAV sync against a self-hosted Nextcloud, reconciling local and remote changes.
- A clean Electron + React + TypeScript interface for capturing journals, notes and tasks.

## Stack

Electron, React, TypeScript, SQLite, CalDAV.
