## Overview

A 24/7 multi-service private cloud running on Ubuntu. It hosts Nextcloud, Vaultwarden, n8n,
Mosquitto and a full Dawarich stack (PostgreSQL/PostGIS, Redis). It handles files, passwords,
automation and location history, all on my own metal.

## What it does

- Every service runs in Docker and is reachable only from devices in my Tailscale tailnet. No
  ports are forwarded and nothing is exposed to the open internet.
- A reverse proxy handles internal HTTPS; certificates are issued via DNS-01 for private hosts.
- Nightly backups follow a 3-2-1 strategy for the databases.

## Stack

Docker, Ubuntu, Tailscale, PostgreSQL, Redis, Apache.

> This project is private.
