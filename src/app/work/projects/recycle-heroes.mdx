Recycle Heroes is an Android app for finding nearby recycling stations on a map, built as a group
project. It uses the Mapbox SDK for the maps and place data, and instead of leaning on a
ready-made HTTP library it talks to the server over a custom asynchronous socket layer, with Gson
handling the JSON on the way in and out. It is written in Java.
