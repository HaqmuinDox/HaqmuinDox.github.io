## Overview

Recycle Heroes is a collaborative Android app for locating recycling stations. It uses the Mapbox
SDK for maps and places, a custom asynchronous socket networking layer for client/server
communication, and Gson for JSON parsing.

## Stack

Java, Android SDK, Mapbox.
